## Supervised Machine Learning

| Algorithm | One-Line Explanation |
|-----------|---------------------|
| **Linear Regression** | Predicts a continuous value by fitting a straight line through data |
| **Ridge & Lasso** | Linear regression with penalty to reduce overfitting |
| **Logistic Regression** | Predicts binary outcomes (Yes/No) using a probability curve |
| **Decision Tree** | Splits data into branches using if-else conditions to classify/predict |
| **Adaboost** | Combines weak models sequentially, each fixing the previous one's errors |
| **Random Forest** | Builds multiple decision trees and takes their majority vote |
| **Gradient Boosting** | Sequentially builds trees where each corrects the previous tree's mistakes |
| **XGBoost** | Faster, optimized version of Gradient Boosting for high performance |
| **Naïve Bayes** | Classifies using probability, assuming all features are independent |
| **SVM** | Finds the best boundary (hyperplane) that separates classes |
| **KNN** | Classifies a point based on the majority label of its K nearest neighbors |

---

## Unsupervised Machine Learning

| Algorithm | One-Line Explanation |
|-----------|---------------------|
| **K-Means Clustering** | Groups data into K clusters based on nearest centroid |
| **DB Scan** | Groups densely packed points and marks outliers as noise |
| **Hierarchical Clustering** | Builds a tree of clusters by merging or splitting groups step by step |
| **PCA** | Reduces dimensions by finding axes of maximum variance |
| **LDA** | Reduces dimensions by maximizing separation between known classes |
